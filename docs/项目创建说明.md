# 按实际需要创建项目

使用scripts/create_project.py，选择research或software根模板，显式给出模板目录、目标目录、项目名和初始要求。默认只预览，--write创建。目标必须不存在；不覆盖已有项目，不联网，不安装依赖，不复制模板维护记录或私有素材。

示例：python scripts/create_project.py --kind research --template-root <科研模板目录> --destination <新项目目录> --name sample --requirement "比较两种方法" --write

当前支持script能力；不支持的能力明确拒绝，不补空服务器或训练目录。创建后只有初始需求、说明入口和必要规则配置。docs状态为尚未建立，不生成假结果。项目具备真实成果后，完成四份可读文档并将配置中的交付状态设为ready，再检查实际使用路径。版本来源保存在项目配置中，不放进读者正文。
