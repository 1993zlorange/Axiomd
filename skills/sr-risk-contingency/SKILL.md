# SR-风险登记与预案

Use this leaf Skill when: 需要管理数据、方法、算力、合作、时间、伦理或投稿风险及 Plan B 时

Before starting, read [../sr-research-shared/references/research-contract.md](../sr-research-shared/references/research-contract.md). Obtain or reconstruct the `human_baseline`, then return the work contract. Do not skip directly to a polished answer.

## Doctoral old-school workflow

1. 按类别列出具体风险事件
2. 估概率、影响和最早可观测信号
3. 为高风险写缓解动作和 Plan B
4. 指定责任人并定期检查触发器

The old-school pass is the researcher's unaided reading, hand calculation, sketch, inspection, or small manual check. Preserve it as an artifact or concise note so AI output can be compared against independent human judgment.

## Human–AI collaboration

**AI role:** 扩展风险场景、挑战盲点、生成触发指标和预案候选。

**Human intervention:** 博士生估计概率影响、承担路线切换，伦理隐私风险交相应负责人。

Pause at that intervention point with options, evidence, uncertainty, and a recommendation. Do not infer approval from silence.

## Deliverable

Use [assets/output-template.md](assets/output-template.md) as the blank document architecture. Name the artifact `YYYYMMDD-内容简述-文档类型.扩展名`; keep the SR ID in frontmatter and keep evidence, conclusion boundaries, and human verdicts explicit.

Use this template: 风险台账：risk / probability / impact / signal / mitigation / Plan B / owner

Recommended optional adapters: None; use available local tools.. Read [../sr-research-shared/references/source-adapters.md](../sr-research-shared/references/source-adapters.md) before using any adapter. Missing adapters are not a blocker; disclose the manual/local fallback.

## Completion gate

高影响风险都有可观测触发器、负责人和可执行预案，剩余风险被接受或升级。

Also require traceable evidence, an explicit conclusion boundary, and the applicable human verdict in the shared closure record. If the gate fails, return `revise`, `pause`, or `reject`; never mark the package complete because a template was filled.
