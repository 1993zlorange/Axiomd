# PS-01 项目治理

先读取当前项目全部适用的 `AGENTS.md`，再读取主监理规范中的[项目监理工作流程](../pr-ps-00-project-supervision/references/20260912-项目监理工作流程-管理规范.md)、[文件命名与归属规范](../pr-ps-00-project-supervision/references/20260912-文件命名与归属-管理规范.md)和[需求日志反思机制](../pr-ps-00-project-supervision/references/20260912-需求日志反思机制-管理规范.md)。

逐条登记用户要求，建立任务 ID、目标、非目标、专业角色、输入、输出、依赖、权限、风险、验收、验证、文件放置和停止条件。检查重复任务、已有写入者和用户未提交改动；冲突未解决时阻塞。

使用 [中文空白模板](assets/20260912-项目治理-输出模板.md)生成需求与操作监督记录，输出到项目 `AGENTS.md` 配置的对应项目管理目录，命名为 `YYYYMMDD-内容简述-文档类型.md`。模板不是批准或证据。

完成标准：每项需求有状态，每个拟写文件有责任与路径，每个高风险动作有授权状态，专业角色获得明确输入，监理能在任务结束时逐项核对。
