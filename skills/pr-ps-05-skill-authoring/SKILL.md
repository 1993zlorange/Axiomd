# 技能编写与优化

沟通方式见 [AGENTS.md](AGENTS.md)：先说结果，用中文解释步骤、依据和限制。

## 什么时候用

创建、改写、合并或完善技能的说明、流程、模板和工具；适用于已有重复需求或用户明确要求编写技能的任务。按任务内容自然使用，不要求用户说出技能名或指定姓名。

## 先看什么

先读用户请求、适用的项目说明和直接相关的现有材料。已有决定继续有效，只询问会实质影响结果的缺失信息。

## 怎么做

1. 列出技能要解决的具体请求，检查现有功能，能合并就不重复创建。
2. 保留稳定的目录与名称，用中文说明什么时候用、需要什么、具体步骤、产物和检查办法。默认允许按自然语言自动选择。
3. 核对要吸收的参考内容当前可访问版本，把必要方法改写进本技能；记录来源与核对日期，不在运行时要求再调用来源技能。
4. 准备贴合任务的中文模板；代码、参数和格式字段保留兼容。仅为重复且可靠的操作维护脚本。
5. 用正常请求、缺失输入、错误情形和相似但不适用的请求检查行为；检查本地链接、生成器与安装清单。

不要求用户点名或填写负责人姓名。遵从用户已有授权，不为明确的技能修改另设启用审批。来源版本无法核实时说明限制。

## 交付什么

按实际用途选用本目录模板，删除不适用的部分；简单回答无需另存文档。需要文件时使用项目已有目录，命名为 `YYYYMMDD-内容简述-文档类型.扩展名`。

- [20260912-技能编写-输出模板](assets/20260912-技能编写-输出模板.md)

## 怎么检查

技能可独立使用，模板能表达实际成果，没有循环调用、重复功能或无法执行的步骤。

本技能直接完成其范围内工作，必要方法已写入本目录。使用现有工具，不递归调用其他技能，不为普通任务增加管理表、额外角色或重复确认。
