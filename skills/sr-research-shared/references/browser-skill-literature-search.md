# 登录数据库的检索

用当前可用浏览器工具和用户授权的现有会话读取检索页面，无需安装或调用额外浏览器技能。先观察页面，再填写检索词、筛选和分页。工具缺失时可以继续公开检索或处理已提供资料，并说明覆盖范围变化。

只保存来源 URL、检索时间、查询式、可见题名、作者、摘要及标识符。不得读取密码、Cookie、令牌、localStorage/sessionStorage 或认证头，不复制登录状态。

登录、验证码、一次性密码和付费确认交由用户处理，不绕过付费墙和访问限制。请求已明确授权的检索不用重复确认。结束时归还借用标签页，不关闭无关页面。

记录实际收集数量和未覆盖部分。授权只覆盖页面读取与检索，不等于允许下载受限全文、改账户或公开数据。
