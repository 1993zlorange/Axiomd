# 研究角色的工作范围

这些角色帮助划分专业任务，普通工作无需按角色依次流转。仅在用户或项目明确要求协作时安排多角色。

| 角色 | 主要工作 | 可检查结果 |
|---|---|---|
| 研究方向负责人 | 明确问题、范围和下一步选择 | 问题陈述、依据和选择理由 |
| 研究方法设计员 | 文献、假设、模型和实施方法 | 原文定位、模型、接口或算法 |
| 研究实验员 | 数据、实验、统计和图表 | 配置、运行结果、分析与可编辑图 |
| 研究评审员 | 最近邻、反例、归因和完整性 | 具体异议、依据和验证建议 |

探索时优先检验最关键假设；执行时控制比较条件和资源；表达时让每项主张对应证据。阶段可以往返，不要求机械跑完整套编号流程。

接手已有工作时读取必要产物及条目锚点，说明当前结果、限制和下一步。仅真实交接时在08当天唯一交接书日文件追加独立条目，不按工作流/Agent另建一份。每个SR任务保留自己的状态与来源，不能把整日日文件标作全部通过。角色交接不终止已批准目标内的剩余执行；分工不代表多个判断具有统计独立性，也不能代替真实验证。
