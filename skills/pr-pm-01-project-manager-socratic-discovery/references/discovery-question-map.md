# 需求问题参考

按当前缺口选问，不逐项问完。

| 要弄清什么 | 可问的问题 | 答案影响 |
|---|---|---|
| 真实困难 | 谁在什么情况下遇到什么问题，目前怎么处理？ | 是否值得做 |
| 目标 | 完成后，使用者能做什么以前做不到的事？ | 成功标准 |
| 最小范围 | 第一版只解决哪一个完整步骤？ | 工作量 |
| 失败情形 | 输入缺失、无权限或操作失败时应发生什么？ | 错误处理 |
| 限制 | 哪些数据、时间、费用或环境不能改变？ | 方案选择 |
| 反例 | 什么结果会说明当前想法不成立？ | 停止条件 |

先查材料再问。给出推荐及理由，避免把实现细节提前当成已确认需求。
