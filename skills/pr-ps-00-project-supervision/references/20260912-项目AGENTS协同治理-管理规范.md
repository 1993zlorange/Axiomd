# 项目说明与可选记录配置

先遵守项目根和当前目录的 AGENTS.md。项目可以规定记录、检查和文件位置，但普通工作不必先调用监理或其他技能；缺少管理配置不影响明确授权的代码、文档或只读工作。

## 需要生成管理记录时

已有配置沿用，未配置时优先项目现有目录。下方配置供本目录的文档生成工具读取，键名为机器接口，保留英文；不要求每个项目建立全部目录。

```project-supervision
project_management_root = "project-management"
requirements_dir = "requirements"
supervision_dir = "supervision"
logs_dir = "logs"
reflections_dir = "reflections"
changes_dir = "changes"
quality_dir = "quality"
costs_dir = "costs"
skills_dir = "skills"
tools_dir = "tools"
templates_dir = "templates"
engineering_root = "."
programming_standard = "PROGRAMMING_STANDARDS.md"
evolution_review_days = 14
repeat_problem_threshold = 3
```

路径相对项目根解析，必须保持在项目边界内。生成工具若缺少必要配置，应明确报错，不猜测路径或跨项目写入；可以先交付文字内容，由用户给出确实需要的目标位置后再生成。脚本对配置的要求不等于整个项目的前置要求。

用户指定的根目录优先，其他情况下从当前项目定位。不要根据开发者机器路径或另一个项目的名称推断。目录仅在有实际产物时创建，不生成空目录树。
