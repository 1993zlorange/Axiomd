# 管理文档写作标准

Status: approved
Approved at: 2026-09-29
Applies to: PR project-management documents generated by Axiom PR Skills

本标准面向项目管理类文档，不替代技术文档规范、测试规范或发布规范。它的目标是让导师、博士生和项目负责人先读懂研究或项目主线，同时保留完整审计链。

## 1. 文档分级

| 级别 | 适用文档 | 写作深度 |
|---|---|---|
| A | 决定记录、呈报、日志、日报、需求记录 | 导师可读的科研/项目叙述；正文零行话、零裸编号、零路径 |
| B | 监督记录、变更记录、反思、交接简报、执行提示词 | 结构和字段保形；只做白话化与长句拆分 |
| C | 质量门禁、成本统计、模板登记 | 证据型保守；只清明显公文词和超长句，表格与证据原样 |

分级决定结构改造深度，不只决定措辞。无法判断级别时按 C 级保守处理，并在人工确认后升级。

新生成文档必须由模板带出 `writing_level`，并使用对应级别的完整结构。既有终态文档审计时可显式指定 A/B/C 级：不强制回填 `writing_level`，不要求标题与新版模板逐字相同，但必须满足概念结构、正文/附录分离和审计安全网。

## 2. A 级结构

A 级正文采用三段式：

```text
背景一句话
→ 研究或项目内容
→ 研究或项目影响
```

要求：

1. 第一段用一句话说明这次记录在研究或项目上的意义；
2. 正文只写做了什么、决定了什么、边界是什么、影响是什么；
3. 文末设“附录：管理信息”；
4. 附录必须包含：
   - 管理信息索引；
   - 正文编号对照；
   - 原记录对照或审计留痕。

A 级正文不得出现：

- 治理编号；
- 文件路径；
- 代码符号；
- 反引号；
- 会话机制描述；
- 未解释的项目管理行话。

正文确需指代时写“见附录”。

## 3. B 级结构

B 级文档以保形为主：

- frontmatter 不动；
- 表格、字段、编号和路径保留在原位置；
- 只改叙述性文字；
- 长句拆短；
- 公文词换成日常表达；
- 不把管理信息移入附录。

B 级用于过程监督和审计，不应为了可读性破坏既有字段。

## 4. C 级结构

C 级是证据型文档：

- 表格、命令、退出码、数值和证据路径原样保留；
- 只清理明显公文词；
- 只拆明显超长句；
- 不重构结构；
- 不移动证据列；
- 不改机器字段。

## 5. 公文词映射表

| 不优先写法 | 优先写法 |
|---|---|
| 具名 | 签字确认；主体遵原文 |
| 检查点 | 待拍板事项 |
| 派发 / 派单 | 安排给 |
| 附登记限制 | 附带几条已登记的限制 |
| AGENTS.md §N | 项目规则；出处见附录 |
| 反思候选 | 待改进事项；攒够次数正式复盘 |
| 呈报 | 提出 / 给出 |
| 属 | 是 |
| 予以 | 删除，或改为具体动作 |
| 旨在 | 删除，或改为“为了” |
| 转正补记 | 升级补记 |
| 两轨 / 事前性条款 | “看结果前先定标准”式白话 |

技术术语如果是当前专业领域必需术语，可以保留，但首次出现要解释。

## 6. 编号规则

正文使用中文称谓，编号进入附录：

```text
正文：研究设计已经导师签字确认。
附录：研究设计签字确认＝HDEC-20260922-001
```

允许例外：

- 标题中的既有编号；
- 用户原话中的编号；
- frontmatter 机器字段；
- B/C 级文档的原位编号；
- 工作流编号首次出现时可写“中文名（编号）”。

## 7. 表格证据列

A 级表格中的路径类证据列写：

```text
（见附录对照）
```

原表格行必须逐字移动到附录“原记录对照”，不得删改。

B 级和 C 级表格不移动证据列。

## 8. 安全网

改写或生成管理文档时必须满足：

1. 编号、数字、路径三类令牌在改写前后多重集守恒；
2. 用户原话引文行逐字保留；
3. “留痕”“不得删除”等审计要求行逐字保留；
4. frontmatter 机器字段不动；
5. A 级正文移入附录的管理信息不丢失；
6. 字母数字标签因背景句新增一次属良性变化，记录即可，不回滚；
7. 结构校验通过不等于事实正确，人工复核仍按项目规则执行。

## 9. 句式

- 短句为主，通常不超过 45–60 个字；
- 纯列举长句可保留；
- 人称使用“导师”“博士生”“本阶段”“本项目”；
- 衔接词使用正常书面表达；
- 不使用“我们”“这轮”“老师”“说白了”；
- 一句至多一个括号，禁止嵌套括号；
- 结论先行，不先铺过程。

## 10. 命名

管理文档命名保持既有规则：

```text
YYYYMMDD-内容简述-文档类型.扩展名
```

不得因 A/B/C 分级改变文件名规则。
