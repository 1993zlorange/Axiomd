# Codex 项目工具包迁移记录

## 1. 迁移范围

本全局技能由一个通用科研/软件项目工具包中的项目治理、质量门禁、反思闭环、Skill 编写、迁移试点、文件组织、日志、变更、成本统计和方法论规则适配形成。来源项目仅作为同类项目模板，不作为运行时依赖。

## 2. 保留的通用能力

- 项目范围、任务、责任、证据和暂停条件；
- L1 至 L5 分层质量门禁；
- 用户需求逐条登记、项目日志、问题/缺陷与反思闭环；
- 文件命名、目录归属、批量操作、Git 与权限安全；
- 新 Skill、脚本工具、API 说明和新文档模板的生成规则；
- 经验提炼、试点、人工批准和周期性演化。

## 3. 适配内容

- 删除来源项目名、固定目录、领域数据和历史结论；
- 所有项目路径改为由当前项目根 `AGENTS.md` 配置；
- 将多个入口收敛为全局 `pr-ps-00-project-supervision` 监理技能；
- 将管理规范拆分到 `references/`，将所有文档输出结构放入 `assets/`；
- 所有规范、流程、Skill 和模板正文改为中文；
- 写入工具默认预览，并要求显式 `--write`。

## 4. 未迁移内容

未迁移任何特定项目的业务 Schema、数据、运行产物、自动循环、自动提交/推送、凭据、机器绝对路径或外部服务写入逻辑。

## 5. 回滚与验证

来源目录不修改、不移动。全局适配版通过 Skill 结构校验、Agent TOML 解析、内部链接检查和三个脚本的隔离试运行验证。回滚时只移除本次新增的全局代理和技能目录，并撤销明确标记的 `AGENTS.md` 增补；不得删除来源工具包。
