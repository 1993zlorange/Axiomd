# 技能与脚本编写

技能保持一个清楚的主要用途，提供自然中文触发说明、输入、步骤、产物、检查及必要限制。目录和 name 一致，使用小写字母、数字与连字符；已有项目代号沿用，不要求用户在请求中说出代号。

默认允许自然语言触发，负责人可用角色或省略。必要方法写入本目录，模板按实际用途设计，不要求运行时调用其他技能或安装扩展。用户明确要求创建或修改时直接完成并验证，不额外设置启用签认。

脚本仅用于值得重复维护的操作。参数化路径，校验输入，默认避免覆盖；有写入预览、退出码、错误、重复执行和恢复说明。凭据、机器路径、隐式联网和自动发布不能写进通用工具。

脚本使用说明与代码同步，写清命令、参数、输入输出和实际验证。普通一次性操作不强制包装成工具或先建登记表。
