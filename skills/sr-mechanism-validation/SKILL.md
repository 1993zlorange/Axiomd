# 机制验证

沟通方式见 [AGENTS.md](AGENTS.md)：先说结果，用中文解释步骤、依据和限制。

## 什么时候用

性能差异之外还需要用中间量、残差、守恒、探针或对照支持声称机制时。按用户的任务自然使用，不要求用户说出技能名，也不要求指定负责人姓名。

## 先看什么

先读用户提供的材料和项目中与这项任务直接相关的文件，明确要回答的问题、已有结果和当前限制。已有手算、草图或研究笔记可以作为比较依据；没有时直接开展工作，不补造人工判断，也不要求用户先完成一套表格。

## 怎么做

1. 从机制主张导出预期可观测变化。
2. 选择能代表机制的中间量或观测手段。
3. 设计随机、替代解释或负对照。
4. 比较结果并评估代理指标有效性。

使用本目录的 [结果模板](assets/output-template.md)。专业内容包括：机制证据表：机制主张 / 预测 / 观测手段 / 对照 / 结果 / 替代解释 / 强度。

## 怎么检查

机制预测、观测手段和对照对齐，代理有效性被讨论，证据强度与措辞匹配。

核对关键数字、来源位置、计算或运行结果；明确哪些是事实、解释、假设和计划。缺少输入时完成能做的部分，并说明缺什么、影响什么。没有运行的实验不能写成已完成，没有证据的推断不能写成结论。
