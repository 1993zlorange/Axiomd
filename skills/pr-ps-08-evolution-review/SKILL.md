# PS-08 进化评估

读取项目 `AGENTS.md` 中的评估周期和重复问题阈值，以及主监理[需求日志反思机制](../pr-ps-00-project-supervision/references/20260912-需求日志反思机制-管理规范.md)和[进化策略](../pr-ps-00-project-supervision/references/20260912-质量门禁与进化策略-管理规范.md)。

汇总评估周期内的全部需求变化、问题类别、反思、质量门、成本时间、成功率、误触发率、重复失败和维护成本。使用 [中文空白模板](assets/20260912-进化评估-输出模板.md)形成 `YYYYMMDD-内容简述-进化评估.md`，写入项目配置的技能目录，列出候选改进、重叠冲突、预期收益、试点、风险和回滚。

只有跨多次证据支持、边界清晰、维护人明确且人工批准的提案才能进入试点；试点通过后仍需人工决定是否修改默认规则。
