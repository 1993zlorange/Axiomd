# PS-02 质量门禁

读取项目质量命令和主监理[质量门禁规范](../pr-ps-00-project-supervision/references/20260912-质量门禁与进化策略-管理规范.md)。按风险执行 L1 静态、L2 单元/契约、L3 集成、L4 用户路径、L5 交付/发布；项目不存在的层级标为“不适用”，不能虚构。

使用 [中文空白模板](assets/20260912-质量门禁-输出模板.md)记录命令、环境、样本、结果、证据、警告处置、未执行原因和残余风险。错误阻断；警告必须有决定。输出命名为 `YYYYMMDD-内容简述-质量门禁.md`。

本 Skill 只作独立质量判断，不修改产品实现，也不代替测试员、正式验收或科研同行评议。
