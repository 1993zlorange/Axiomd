# 软件发布准备

沟通方式见 [AGENTS.md](AGENTS.md)：先说结果，用中文解释步骤、依据和限制。

## 什么时候用

准备本地发布包、版本说明、安装验证和回滚方案；适用于打包、发布候选及用户已授权的发布任务。按任务内容自然使用，不要求用户说出技能名或指定姓名。

## 先看什么

先读用户请求、适用的项目说明和直接相关的现有材料。已有决定继续有效，只询问会实质影响结果的缺失信息。

## 怎么做

1. 确定版本、交付范围和目标环境，读取项目发布约定、变更、测试和迁移说明。
2. 按清单准备代码或构建结果、锁文件、配置示例、文档、许可和恢复办法；排除秘密、真实日志及无关内部材料。
3. 在干净环境检查安装或启动、核心功能与升级恢复，保留实际命令和结果。
4. 先完成可审查的本地候选包和说明；上传、部署、重启或签名仅在相应动作已获授权时执行。
5. 记录实际发布位置、版本、检查结果和恢复状态；未执行的外部动作明确标为未执行。

候选包不等于正式发布。高风险缺陷或关键验证失败时说明影响并保持候选状态；已有发布授权无需重复索取。

## 交付什么

按实际用途选用本目录模板，删除不适用部分；简单回答无需另存。过程记录按项目、上海记录日和规范类型定位唯一日文件，任务为独立条目，不按内容简述或运行ID拆文件；无真实内容不创建。正式方案、API说明、手册等实体文档按对象身份持续维护，不能换名规避日记录规则。

## 怎么检查

内容与清单一致，版本可追踪，安装和核心功能有实际检查，恢复方法清楚。

本技能直接完成其范围内工作，必要方法已写入本目录。使用现有工具，不递归调用其他技能，不为普通任务增加管理表、额外角色或重复确认。
