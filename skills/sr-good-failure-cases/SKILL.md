3. 叠加输入、真值、预测和误差。
4. 逐项检查数据正确性并归纳共性。

## 交付什么

使用本目录的 [结果模板](assets/output-template.md)。专业内容包括：案例卡：选择规则 / 输入特征 / 真值 / 预测 / 误差 / 共性 / 假设。

## 怎么检查

案例按规则选择且可定位，数据已核查，共性转成可证伪原因而非故事。

核对关键数字、来源位置、计算或运行结果；明确哪些是事实、解释、假设和计划。缺少输入时完成能做的部分，并说明缺什么、影响什么。没有运行的实验不能写成已完成，没有证据的推断不能写成结论。
