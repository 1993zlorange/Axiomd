# 可编辑科研示意图

先写主要结论、节点含义和连接关系，再选择布局。采用未压缩 mxGraph XML，保留 mxfile、diagram、mxGraphModel、root 及基础单元；每个节点和边使用唯一稳定标识。

节点明确设置位置和尺寸，优先网格对齐；预留连线走廊。边连接真实 source 和 target，避免悬空箭头。分组、页面、父子关系和既有标识在局部修改时保留。

用形状表达对象类型，用箭头表达明确的数据流、步骤或因果含义。公式独立成单元，启用 `math="1"`，正确转义 XML 特殊字符。长文本缩短或拆图，不缩到难读。

保存后运行本目录的 qa_drawio.py，检查标识、引用、几何、数学标签和布局问题；再通过 diagrams.net/draw.io 导出预览，核对内容与源一致。没有预览工具时交付源文件并说明未完成视觉检查。
