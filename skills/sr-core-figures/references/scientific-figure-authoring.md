# 科研数据图制作

先确定这张图要回答的问题与唯一结论，再选图型。填写本目录的图表说明：数据来源、样本量、比较对象、视觉编码、单位、不确定性、图注和不能支持的结论。

## 选图

| 要表达什么 | 建议图型 |
|---|---|
| 成本或耗时 | 汇总柱、原始重复点、误差定义和样本量 |
| 条件间差异 | 绝对值加有符号差值，或配对图 |
| 预测一致性 | 真值与预测散点、等值线及独立残差图 |
| 误差结构 | 原始点、均值或中位数、区间及分箱说明 |
| 参数覆盖 | 参数空间图，区分已知、插值与外推 |
| 场分布 | 标出物理量、区域、单位和统一色棒范围 |
| 长期稳定性 | 时间曲线、参考结果与增长量 |

多面板只用于直接比较，面板编号和阅读顺序清楚。不把一张图塞成多个无关目标。

## 保留数据含义

每次改图都核对原始值、点数、样本量、重复次数、排除规则和派生指标。保存原始数据、变换、归一化和分箱规则，不删不利样本，不补画缺失观察，不事后添加显著性。保留数据校验值和版本。

误差条说明是范围、四分位距、标准差还是置信区间。相关性、预测效果与因果机制不能混淆。计划和实际结果用清楚的文字及样式区分。

## 排版

默认中文；投稿或用户要求英文时使用相应语言。统一字体、字号和单位。图例有清楚的对象、符号和留白，不遮数据；可采用白底黑边方框。颜色含义全组一致，结合线型或点形，不只靠颜色区分。避免彩虹色图和误导性的双轴或截断坐标。

## 导出与检查

从版本化脚本导出 SVG/PDF，必要时另附高分辨率位图。检查实际导出的文字、图例、单位、边距、透明背景与数据一致性。期刊尺寸和格式按具体期刊当前要求核对，不声称某个固定 DPI 保证合规。

本目录检查器只能检查结构和已填信息，不能证明科学结论或视觉效果正确。无法导出时标明限制并交付可编辑源。
