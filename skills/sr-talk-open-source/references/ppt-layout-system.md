# 演示文稿版式选择

每页先确定主要内容类型，再选版式。结论页突出一句结果和少量依据；截图页让实际画面占主要区域；机制页用对应关系；流程页按顺序；架构页按层次；案例页按输入、动作和结果。

| 版式标识 | 用途 | 文字与视觉建议 |
|---|---|---|
| claim | 结论与背景 | 约 60% / 40% |
| evidence-screenshot | 实际产物或页面 | 约 30% / 70% |
| mechanism-map | 解释与对应关系 | 约 45% / 55% |
| process-flow | 顺序或循环 | 约 25% / 75% |
| architecture | 层次与模块 | 约 25% / 75% |
| case | 具体使用实例 | 约 40% / 60% |
| reflection | 已发生问题与改进 | 约 55% / 45% |

这些比例用于初稿，不替代实际阅读检查。16:9 页面预留标题、总结、主体和来源区域，边距至少一个 24pt 汉字。连续页面可以随内容调整密度与布局。

少于约 220 个可见字且单一问题通常可读；220–320 字需检查密度；超过 320 字、两个主要问题、两句总结、超过 12 个节点或三条分支时优先拆页。例外要说明理由并以渲染效果验证，不能仅改字段绕过检查。
