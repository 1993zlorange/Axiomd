# 从文档制作演示文稿

## 提取和组织

先读题名、摘要、结构、图注与表注，再回到支撑结论的方法和结果。建立术语表，统一模型、数据、指标和缩写。每条论点注明源页、图表或数据，缺项直接标出。

建立材料覆盖表，决定哪些进入正文、讲稿或备份页。按主要问题拆页，再调整字数；方法、结果、案例和下一步计划不要互相挤占。

普通学术报告按问题—方法—证据—限制组织。组会过程回顾 `group-meeting-process-review` 可按背景、主要结果、材料、原因、方法、案例和下一步组织，页数服从时长及材料。

## 模板与版式

优先用户模板，否则复制本目录的脱敏组会模板。选择版式见 [版式选择](ppt-layout-system.md)，逻辑图见 [逻辑图说明](logic-diagram-style.md)。每页一个主要对象、一句总结、一组对应材料。

使用 20260830 v8 组会风格时，保留通栏标题与章节编号；涉及物理模型时列激励、几何、介质、边界四要素；资源统计写单位和可比条件；图表写坐标、物理量、单位与图例，透明图背景和色棒仍需可读。

## 交付

生成实际可打开的 PPTX 和讲稿，结构校验后逐页渲染修正。检查溢出、字体、颜色、图表、单位及来源；不能只交大纲却声称完成 PPT。用户修改稿按 [修改对照](human-revision-retrospective.md) 分析，保持个别偏好与通用规则分开。
