# 脱敏组会模板说明

模板只包含重建的布局和说明，没有原始研究图、原始幻灯片截图或私有项目数值。复制后替换占位内容，作者指导页与反面示例页默认删除。

保留通栏标题、章节编号、主结论和安全边距。可以从四类视图选版式：文字论点、图表证据、机制流程、对比表格。涉及模型时列激励、几何、介质、边界；资源统计保留单位和定义。

正文目标 20pt，图表最低 14pt。默认配色为蓝 #003399、浅蓝 #D9E2F3、红 #C00000、正文 #262626、边框 #BFBFBF。关键内容红色加粗下划线，重要内容蓝色加粗，普通内容黑色。不用圆圈序号，使用普通数字。

结果页让方法退居次要位置；重复模块突出变化部分。模板中的文字只是提示，不能当作实际研究结果。最终检查实际文件和逐页计划是否一致。
