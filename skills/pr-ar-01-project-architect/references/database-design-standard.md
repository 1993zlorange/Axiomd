# 可直接实现的数据库设计

从真实读写场景出发，明确数据由哪个模块维护、保存多久、如何检索和删除。先确定事务、并发、离线及恢复要求，再选择存储方案。

## 表与字段

每张表写用途、主键、外键、唯一约束和生命周期。每个字段写数据库类型、长度或精度、是否可空、默认值、单位、范围及来源。主键生成、时区、时间精度、字符编码和枚举规则保持一致。

## 查询与事务

用典型查询说明索引理由，检查组合索引顺序、分页与排序稳定性。写出事务边界、隔离级别、锁或乐观并发条件、冲突返回、重试次数及幂等键。说明外键删除策略，避免孤立记录或意外级联删除。

## 建表与迁移

提供与目标数据库相符的建表语句或迁移文件；验证约束、索引和代码数据类型一致。列出旧版兼容、字段回填、失败中止、备份和回滚。不可逆的数据转换必须先保留可恢复副本，并确认授权。

## 验证

以最小样例检验正常写入、空值、重复键、错误关联、并发冲突和删除。检查查询计划及重要路径性能。给出备份恢复步骤与实际测试结果；未测试明确说明。缺少具体字段和事务行为的概念图不能作为实现完成的设计。
