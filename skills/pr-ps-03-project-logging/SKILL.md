# 工作事实记录

沟通方式见 [AGENTS.md](AGENTS.md)：先说结果，用中文解释步骤、依据和限制。

## 什么时候用

在一次操作或运行结束后记录实际改变和验证结果；用于项目要求留痕或用户要求记录工作。按任务内容自然使用，不要求用户说出技能名或指定姓名。

## 先看什么

先读用户请求、适用的项目说明和直接相关的现有材料。已有决定继续有效，只询问会实质影响结果的缺失信息。

## 怎么做

1. 收集本次实际动作、产物、错误、检查结果和用户反馈。
2. 按时间或工作结果整理，明确完成、失败、跳过和未执行，计划另列。
3. 记录关键文件和必要时间成本，没有测量的数据写未记录。
4. 写入项目已有日志位置，保留原记录和可定位来源，检查敏感信息。

不自动为普通问答创建日志；不从文件时间猜测人工工作时长，不把未来计划写成已完成。

## 交付什么

按实际用途选用本目录模板，删除不适用的部分；简单回答无需另存文档。需要文件时使用项目已有目录，命名为 `YYYYMMDD-内容简述-文档类型.扩展名`。

- [20260912-项目记账-输出模板](assets/20260912-项目记账-输出模板.md)

项目日志按 A 级生成；沿用模板必需结构，管理字段集中在附录，不在正文堆叠编号。

## 怎么检查

所有事实来自本次可见证据，结果与状态一致，源材料未被改写。

本技能直接完成其范围内工作，必要方法已写入本目录。使用现有工具，不递归调用其他技能，不为普通任务增加管理表、额外角色或重复确认。
