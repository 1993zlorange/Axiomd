# 网页界面检查

页面让用户看清当前状态和主要操作；文字、间距和颜色形成稳定层级。根据产品内容设计，避免所有页面套相同卡片。装饰不应妨碍任务。

逐个操作本次改变的按钮、表单、列表和导航；覆盖加载、空内容、错误、成功、重复操作和状态过期。检查刷新、返回、持久化与接口一致。

表单有标签和错误定位，键盘可操作，焦点可见，状态变化可被辅助技术理解。检查宽屏和窄屏、滚动、文字溢出、图片加载和减少动态效果设置。

用真实浏览器执行关键路径，保存必要截图及实际结果。无法运行时明确未验证项，不以静态代码检查替代运行检查。

语义元素优先：动作用按钮，导航用链接，表单有可关联标签，图像有替代文字。异步状态应可被辅助技术感知；固定浮层不能遮住焦点。允许粘贴，错误靠近字段并定位首个错误。处理未保存离开、长文本和空列表；图片声明尺寸避免布局跳动，长列表按性能实测选择虚拟化。
