# PS-06 脚本工具编写

读取项目编程规范和主监理[Skill 与脚本生成规范](../pr-ps-00-project-supervision/references/20260912-技能与脚本工具生成-技术规范.md)。脚本源文件及标识符按项目语言规范命名；路径必须参数化并限定在项目边界，写入默认预览，拒绝隐式联网、凭据、提交、发布和覆盖。

可使用主技能工具 `scripts/ps_03_create_script_tool.py` 同批生成脚本骨架与 API 说明。使用 [中文空白模板](assets/20260912-脚本工具-输出模板.md)记录调用、参数、输入输出、退出码、错误、安全、幂等、并发、验证、兼容和回滚。API 文档命名为 `YYYYMMDD-内容简述-API说明.md`。

脚本与 API 说明任一缺失、测试未运行或路径越界时，任务不得关闭。
