# 项目日志日报汇总

沟通方式见 [AGENTS.md](AGENTS.md)：先说结果，用中文解释步骤、依据和限制。

## 什么时候用

读取指定日志目录，按文件名前缀日期生成中文日报；支持单日、日期区间或全部日期。按任务内容自然使用，不要求用户说出技能名或指定姓名。

## 先看什么

先读用户请求、适用的项目说明和直接相关的现有材料。已有决定继续有效，只询问会实质影响结果的缺失信息。

## 怎么做

1. 优先使用用户给出的目录，否则读取项目已有日志配置；找不到明确输入时再询问。
2. 开始前保存输入文件清单，默认只读第一层名称以“日志”结尾的文本文件，支持 md、txt、log、json 和 jsonl。
3. 日期仅取合法的 YYYYMMDD 文件名前缀；未指定日期时用用户当前本地日期，不用文件修改时间猜测。
4. 逐份提取实际动作、产物、验证、问题与未完成项；重复内容合并并保留来源，冲突内容并列。
5. 每个有有效日志的日期生成一份日报，放入项目约定的 dailylogs；同名文件不覆盖。没有匹配日志则说明，不创建空日报。

只读源日志，不删除、移动或改写它们。生成日报后新增的日志不进入本次输入快照，避免循环汇总；损坏文件和非法日期记录为跳过。

## 交付什么

按实际用途选用本目录模板，删除不适用的部分；简单回答无需另存文档。需要文件时使用项目已有目录，命名为 `YYYYMMDD-内容简述-文档类型.扩展名`。

- [20260913-项目日志日报汇总-输出模板](assets/20260913-项目日志日报汇总-输出模板.md)

## 怎么检查

报告日期、来源清单和实际内容一致；计划没有写成完成，敏感信息未输出，同名保护有效。

本技能直接完成其范围内工作，必要方法已写入本目录。使用现有工具，不递归调用其他技能，不为普通任务增加管理表、额外角色或重复确认。
